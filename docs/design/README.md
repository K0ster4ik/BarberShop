# Дизайн-концепты

Макеты от Codex (навык `codex-ux`, режим A) — направление, а не попиксельная спецификация.
Реализация следует токенам shadcn/ui, требованиям доступности и DESIGN.md там, где макет их нарушает.

| Файл | Что это | Решение |
|---|---|---|
| `booking-concept-dark.webp` | Мастер записи, шаг «Дата и время», тёмная тема «Тёмный премиум» | Выбрано пользователем 2026-10-28 как тёмная тема |
| `booking-concept-light.webp` | Светлая вариация того же концепта, 4 шага записи | Сделано по просьбе пользователя как светлая тема |

Сессия Codex мастера записи: `01a182e3-584a-78b3-9cfd-58f3c986dcd7`.
