# Изображения для демо-данных

Сгенерированы OpenAI Codex (навык `codex-image`). Все люди вымышленные. Сброс демо копирует
файлы в папку загрузок (`UPLOADS_DIR/masters/`) и проставляет мастерам `photoPath`.

Фото кодируются из PNG-оригинала Codex тем же способом, что и загрузка в CRM (WebP 4:5,
качество 90, не больше 1200×1500):

```bash
npx tsx scripts/encode-seed-photo.ts ~/.codex/generated_images/<сессия>/<файл>.png master-<имя>
```

Скрипт добавляет к имени хэш содержимого. `/uploads` раздаётся как immutable, поэтому новое
изображение обязано получить новое имя — иначе браузеры и `next/image` покажут старое. После
замены поправьте `photo` в `src/server/demo/catalog.ts` и удалите прежний файл.
