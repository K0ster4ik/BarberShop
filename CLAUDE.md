# Барбершоп: правила работы

Источник правды по продукту и архитектуре — [DESIGN.md](DESIGN.md). Меняются модель данных или
принятые решения — обнови его в том же этапе.

## Общение

С пользователем — по-русски. Интерфейс и сообщения для пользователей приложения — на русском,
код и названия сущностей — на английском.

## Процесс по этапам (DESIGN.md, раздел 15)

1. Каждый этап — в своей ветке `stage-NN-<slug>` от `main`.
2. Перед сдачей: `npm run check`, `npm run test:integration`, `npm run build` и проверка в
   браузере на запущенном приложении (навык `next-dev-loop`).
3. Затем Codex: `codex-review` — на каждом этапе; `codex-ux` (разбор скриншотов) — если менялся
   интерфейс; `codex-qa` — если менялись пользовательские сценарии. Подтверждённые находки
   исправить, итог — таблицей в отчёт об этапе.
4. Коммит в ветке этапа и остановка: пользователь делает ревью.
5. После ревью пользователь пишет «коммит этап N», «гит коммит», «проверен» — это приёмка:
   влить ветку в `main` (fast-forward) и удалить её.
6. Push в `origin` (github.com/K0ster4ik/BarberShop) — только по явной просьбе.

## Команды

| Команда | Что делает |
|---|---|
| `npm run db:up` / `db:seed` | Postgres в Docker и демо-данные |
| `npm run dev` | dev-сервер, http://localhost:3000, CRM — `/admin` |
| `npm run check` | lint + typecheck + Prettier + юнит-тесты |
| `npm run test:integration` | интеграционные тесты на отдельной БД `*_test` |

## Окружение (Windows, Git Bash)

- Postgres для разработки слушает порт 5433: 5432 занят локально установленным Postgres.
- Git Bash превращает аргументы вида `/foo` в пути Windows. Для `git sparse-checkout` и
  похожих команд ставь `MSYS_NO_PATHCONV=1`.
- Вход в CRM ограничен 10 попытками за 10 минут с одного IP, а локально все запросы идут с одного
  адреса. При частых браузерных прогонах перезапусти dev-сервер, чтобы сбросить счётчик.
- HTTP-вход Better Auth закрыт, поэтому `curl` на `/api/auth/sign-in/email` получает 404. Сессию в
  скриптах получай через форму входа в браузере (agent-browser, `#login-email`, `#login-password`).
- Turbopack хранит кэш dev-сборки на диске в `.next`. Если правка `globals.css` не применяется даже
  после перезапуска, останови dev-сервер, удали `.next` и запусти заново.
- Скриншоты агентом: после открытия выезжающей панели (меню, диалог) жди ~600 мс, иначе кадр
  попадёт на середину анимации.
- Codex CLI вызывается только через `node scripts/codex/run.mjs` (см. навыки `codex-*`). Если
  авторизация слетела (код выхода 2), попроси пользователя выполнить `codex logout && codex login`.
- Сторонние навыки, их источники и лицензии — в `.claude/skills/README.md`.
